# AI 辅助 · 现象 → 问题 → 工具 · 提示词模板

> 用途：从**生活现象 / 生活中的例子 / 科学问题**出发，走完
> 「现象 → 科学问题 → 数学模型 → 我们的工具解决」的完整链条，
> 找到能用我们工具箱（decoupling / Kolmogorov 方程函数空间）真解决的问题。
> 与 `science-topic-prompts.md`（数学领域内找题）的区别：这里以**现象为入口**。
>
> **核心原则**：现象只是入口，判据仍是数学结构——方程有没有
> **退化曲率 + 各向异性几何**（Kolmogorov 型）或 **色散振荡**（Schrödinger / 波动型）。
> 禁止因为"随机 / 扩散 / 波动"字眼硬扯关系。

## 使用方法

1. **先跑 GPT 版**：让它从生活现象出发做深度探索，给出 5 个候选的完整链条。
2. **再跑 Danus 版**：让它逐条验证链条的每一环（现象真实性 → 问题可量化 → 模型准确 → 工具对口）。
3. **对比两边输出**：链条两环以上被质疑的 → 弃；两边都通过的 → 可信。
4. 输出与 `docs/topic.md` 的候选对照：A/B（降级方向）、D/E（对口方向）。

## 共用背景块（两个版本提示词都先粘贴这段）

```text
【我们的工具箱（解决问题的手段）】
- Bourgain–Demeter 解耦（decoupling）及其帽分解机制
- 各向异性伸缩 / 抛物型 Littlewood–Paley 分解
- Kolmogorov 型退化抛物算子：K = ∂_t + v·∇_x - Δ_v，
  次椭圆（Hörmander 括号条件），各向异性缩放 (t,x,v) ↦ (r²t, r³x, rv)，
  基本解为各向异性高斯（这是我们正在构造 decoupling 函数空间的载体）
- Strichartz / 色散估计、振荡积分 / FIO
- 混合范数 L^p 估计与 Besov / Triebel 型函数空间

【生活/科学现象池（参考，不限于此）】
大量个体随机运动或波动、可在生活或实验室中观察到的例子：
- 显微镜下花粉 / 尘埃在液体中的布朗运动——我们同时观测它的位置与速度
  （位置-速度耦合 = Langevin 动力学 = Kolmogorov 方程的背景）
- 墨滴 / 染料 / 烟雾在介质中的扩散
- 高速公路车流密度波、人群在拥挤通道中的流动
- 声波 / 光在浑浊或有散射体的介质中的传播
- 颗粒在湍流中的输运与扩散
- 病原体 / 信息在人群网络中的传播

【现象 → 问题的转化要求】
对每个现象，必须提炼出**可量化、可证伪**的科学问题（例如：
"花粉颗粒的位置-速度联合分布如何随 t 演化？其密度函数满足什么方程？"），
而不是停留在现象描述。
```

## GPT 版提示词（现象驱动的深度探索）

```text
我是调和分析方向的研究者，熟悉 Bourgain–Demeter 解耦、各向异性 Littlewood–Paley 分解、
Kolmogorov 型次椭圆算子、Strichartz 估计与 Besov/Triebel 型函数空间。背景见上方【背景块】。

我们的目标：从**生活现象**出发，提出一个科学问题，并判断能否用我们的工具解决。
请严格按下面 5 步做，全程区分"有文献依据"与"你的推断"：

第 1 步 · 现象：从【现象池】中选 5 个（也可补充你认为更好的），每个用一两句话
  描述其"大量个体随机运动 / 波动"的本质，并说明普通人能否观察到（生活性）。

第 2 步 · 问题：对每个现象，提炼一个**可量化、可证伪**的科学问题。
  例子：布朗运动 → "花粉颗粒的位置-速度联合分布密度 p(x,v,t) 满足什么方程？
  其核的 L^p 时空衰减率是多少？"（注意：问题要具体到能写方程、能算估计）

第 3 步 · 模型：写出描述该问题的方程 / 算子（例如：K = ∂_t + v·∇_x - Δ_v、
  e^{tΔ}、i∂_t u = -Δu、∂_t ρ + ∂_x J = 0 等），并判断类型：
  (a) Kolmogorov 型（退化抛物、次椭圆、各向异性缩放）？
  (b) 色散型（酉演化、振荡相位）？
  (c) 抛物型（实阻尼、无振荡）？

第 4 步 · 工具：我们的工具箱能否处理？关键判据（只认结构，不认字眼）：
  - 若是 Kolmogorov 型：退化曲率 + 各向异性几何能否被 decoupling 帽分解框架处理？
    （这正是我们正在构造的"适配 Kolmogorov 方程的 decoupling 函数空间"的用武之地）
  - 若是色散型：是否有非平凡相位曲率 / 退化集可做帽分解？
  - 若是抛物型：明确说"工具用不上，降级"。
  给出你认为最对口的 1 个候选作为首选。

第 5 步 · 输出：一张完整链条表——
  现象 | 科学问题 | 方程/算子 | 类型 | 工具对口性 | 信心 | 文献入口（真实可查，标"待核"）

特别要求：优先考虑"布朗运动的位置-速度观测"这类能自然落进 Kolmogorov 方程框架的现象，
因为它与我们正在构造的函数空间直接相关；但不要只给这一个，保持 5 个候选的多样性。
```

## Danus 版提示词（链条逐环验证）

```text
任务：从生活现象出发验证"现象 → 问题 → 模型 → 工具"链条。背景见上方【背景块】。

请对每个候选现象严格分步回答，每步给"是/否 + 一句话理由"，并标信心（高/中/低）：

第 1 步 · 现象真实性：这个现象是否真实存在、可观察、有实验或定量数据文献支撑？
  给出 1 个可查的观察来源（教材 / 论文 / 实验记录）。

第 2 步 · 问题可量化：提炼出的科学问题是否可量化、可证伪？
  是否具体到能写出方程、能定义"要估计的量"（如核的 L^p 范数、衰减率）？

第 3 步 · 模型准确：描述它的方程 / 算子是什么？写出方程。
  判断类型：Kolmogorov 型（次椭圆、各向异性）/ 色散型 / 抛物型。
  模型与现象是否匹配（不要"名字像就套"）？

第 4 步 · 工具对口：我们的工具箱（decoupling、各向异性 LP、Kolmogorov 函数空间、
  Strichartz、FIO）能否处理这个方程的估计问题？判据是结构（退化曲率、各向异性几何、
  相位曲率），不是现象里有没有"随机 / 扩散 / 波动"字样。
  若只是抛物型（实阻尼无振荡）→ 明确"降级"。

第 5 步 · 输出表格：现象 | 问题 | 方程 | 类型 | 对口性 | 信心 | 文献 | 最大风险点。

注意：不要因为现象"看起来随机"就选，也不要因为"看起来不随机"就排除——
唯一的判断标准是第 4 步的数学结构判据。参考 Kolmogorov 1934（布朗运动位置-速度）
与近期退化超曲面 decoupling（arXiv:2507.02134）的思路。
```
