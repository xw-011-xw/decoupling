# AI 辅助科学选题 · 提示词模板

> 用途：让 GPT 和 Danus（DeepSeek harness）帮忙在"大规模粒子随机游动"领域里，
> 找与我们调和分析工具箱（解耦 / Strichartz / FIO / L^p 估计）**数学结构真对口**的研究问题。
> 核心原则：问结构不问名词；强制 AI 标注信心；拒绝"扩散"二字硬扯关系。

## 使用方法

1. **先跑 GPT 版**：利用它推理强的优势，做深度探索，给出 3–5 个候选 + 数学分析。
2. **再跑 Danus 版**：利用它可拆解的优势，按流程穷举 + 逐环节验证。
3. **对比两边输出**：
   - 两边都提到的候选 → 可信度高
   - 只有 GPT 提到、Danus 验证降级的 → 大概率是名字像，弃用
   - 只有 Danus 提到的 → 补查文献后再判断
4. 新候选和 `docs/topic.md` 的 A/B/C/D 对照，印证或补充。
   （当前重点方向：B 图/格点离散谱、D 量子随机游走 / 随机介质中的波）

## GPT 版提示词（深度探索）

```text
我是调和分析方向的数学研究者，熟悉以下工具：
- Bourgain–Demeter 解耦（decoupling）
- Schrödinger 方程的 Strichartz 估计
- 振荡积分 / Fourier 积分算子（FIO）
- 二进频率壳分解、球面帽分解
- 混合范数 L^p 估计

我们组正在为"大规模粒子随机游动"（格点/图上的扩散、密度与涨落）这个科学方向找一个
数学上真实对口的研究问题。

**我们目前特别感兴趣的方向（但不限于）：**
- 量子随机游走（quantum random walk）——演化算子是酉的、色散型的
- 随机介质中的波（wave propagation in random media）——波包在随机散射体中传播
- 图/格点上随机游走的谱分析与离散限制问题

请你不要泛泛而谈，也不要因为"扩散"二字就硬扯关系。请帮我做两件事：

1. 在随机游动 / 概率极限理论领域里，找出 3–5 个具体问题，其数学结构本质上是
   色散方程的 L^p 时空估计、振荡积分估计、或球面限制型估计——也就是我们上面列的工具
   真正能派上用场的地方。除了上面列的三个方向，如果你发现了其他我们没想到的对口方向，
   也请一起列出来。

2. 对每个候选，请给出：
   - 具体模型（比如 Z^d 上的简单随机游走、Lévy 飞行、量子随机游走、随机介质中的波、SSEP 密度涨落……）
   - 对应的方程 / 算子（比如 e^{tΔ}、(-Δ)^{α/2}、离散 Laplacian、色散酉算子……）
   - 为什么这个估计是"色散型"而不是"抛物型"（这是关键判断）
   - 一两个具体的入门文献或教材

最后请明确标注：哪些候选你有把握方程层面真的对口，哪些你只是猜测。
如果某条只是名字像但方程层面不沾边，请直接说"不要选这个"。
```

## Danus 版提示词（结构化穷举 + 验证）

```text
任务：帮我穷举并评估"大规模粒子随机游动"领域里，与调和分析色散估计对口的研究问题。

【我们的工具箱】
- 解耦（decoupling）
- Schrödinger Strichartz 估计
- FIO / 振荡积分
- L^p 混合范数估计
- 频率壳 / 球面帽分解

【工作流程，请严格分步执行】

第 1 步：列出随机游动领域的 5–7 个不同具体模型（不要重复同类）。
  已知候选方向（必须覆盖到，发现新的也请补上）：
  - 经典随机游走 / 扩散极限（Z^d 上的简单随机游走）
  - Lévy 飞行 / 稳定过程（分数阶 Laplacian）
  - 图/格点上的随机游走与谱分析
  - 量子随机游走（quantum random walk，酉演化）
  - 随机介质中的波（wave propagation in random media）
  - 多粒子系统密度涨落 / SPDE（SSEP、KPZ 类）

第 2 步：对每个模型回答下面 5 个问题，每个问题给出"是/否 + 一句话理由"：
  (a) 其长时间演化由哪个方程 / 算子描述？写出方程。
  (b) 这个方程是抛物型（光滑、指数衰减、无振荡）还是色散型（振荡、Strichartz 型、酉演化）？
  (c) 我们上面的工具箱里，哪个工具最可能用来估计这个方程的解？
  (d) 如果只是抛物型，解耦工具用不上，请明确说"这个候选降级"。
  (e) 你对这条的信心：高 / 中 / 低。

第 3 步：挑出信心"高/中"的候选，给出每个的入门文献 1–2 篇。

第 4 步：最后输出一个表格：候选 | 方程 | 类型(抛物/色散) | 对口工具 | 信心 | 文献。

注意：不要因为"扩散""波动""随机"这些词长得像就选。
判断标准只有一个：方程的数学结构是不是色散型 L^p 估计问题。
特别提醒：血流 CFD、纯流体力学 Navier–Stokes 这类是抛物型+应用方向，
我们的解耦工具用不上，请直接降级。
```
