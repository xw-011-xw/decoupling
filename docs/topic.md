# 科学问题初步选题

> 任务来源：AI4Math 第四次实践课 · 任务二（副线）
> 解耦组对应科学方向：**大规模粒子随机游动**（如格点 / 图上的扩散、密度与涨落；先确认与频率解耦的连接）
> 注意：候选不是结论。名称相同、方程形式相似不足以证明两者有联系；本轮只做初步选题，不做完整论证。

## 核心思路

**从我们自己的数学工具箱出发，不从物理名词出发。**

我们手里的工具是：Bourgain–Demeter 解耦、Schrödinger 方程的 Strichartz 估计、FIO / 振荡积分估计、二进频率壳与球面帽分解、混合范数 L^p 估计。这些工具擅长处理的是**色散方程解在时空上的 L^p 估计**——核心特征是**振荡**。

因此真正的桥梁不是"扩散"二字，而是：**在粒子随机游动的世界里，哪里出现了振荡 / 色散 / 时空 L^p 估计问题？** 热方程（抛物型）解光滑、指数衰减，解耦工具在那里只是普通调和分析；真正对口的是有色散特征的游动，以及长时间大空间尺度下概率密度的 L^p 集中与衰减估计。

下面列三个候选，标注联系强度（"有依据" = 方程/估计对象直接是我们熟的；"猜测" = 跨学科跨度大，需后续读文献验证）。

## 候选 A · 扩散极限与热核的 L^p 估计

**对象 / 现象**：Z^d 上的简单随机游走（或连续时间随机游动 CTRW），长时间（t → ∞）下概率密度收敛到高斯热核；研究概率密度在时空混合范数下的衰减、集中与局部时间行为。

**可能的联系**：
- 随机游走的转移概率 p_t(x) 在扩散极限下 ≈ 热核 G_t(x) = (4πt)^{-d/2} e^{-|x|^2/4t}，即抛物算子 e^{tΔ} 的基本解。
- 我们可以从 L^p 估计的角度重新看密度衰减：例如 \|p_t\|_{L^p_x} 的精确衰减率、离散与连续（格点 vs R^d）估计的对比。
- 延伸到**有色散的游动**：Lévy 飞行 / 稳定过程对应的生成元是分数阶 Laplacian (-Δ)^{α/2}，其演化算子兼具抛物与色散特征，解耦 / 球面估计可能直接适用。

**联系强度**：**有依据**（抛物 / 色散算子的 L^p 时空估计是调和分析标准对象；但"经典抛物情形解耦用不上劲"，真正对口的是推广到分数阶 / 色散游动的部分）。

**入门资料**：
- Lawler & Limic, *Random Walk: A Modern Introduction*（扩散极限、热核章节）
- Tao, *Nonlinear Dispersive Equations: Local and Global Analysis*（Strichartz 估计基础，我们自己熟的那头）
- Bourgain–Demeter, A proof of the decoupling conjecture, Ann. Math. 2015（解耦在球面上的应用）

## 候选 B · 图 / 格点上的随机游走与离散调和分析

**对象 / 现象**：Z^d 或更一般（非周期、非欧）图上的简单随机游走；关注其连续谱、Green 函数估计、局部时间（local time）、以及游走在长时间下的"返归"与"扩散剖面"。

**可能的联系**：
- 图 / 格点上 Laplacian Δ_G 的谱分析本身就是一个离散限制问题：谱测度在连续谱上的集中、球面（等能面）的离散几何。
- 我们熟悉的二进频率壳分解、单位球面帽分解，在格点上有直接的离散对应（离散乘子、离散限制猜想）。
- 随机游走的 Green 函数 G(x,y) = ∫ p_t(x,y) dt 本质上是 (-Δ_G)^{-1} 的核，其估计 = 离散调和分析里的核衰减估计——这和我们做 FIO 核估计的路子相通。

**联系强度**：**有依据**（离散限制理论、图上调和分析是活跃方向；我们的频率分解工具天然适配）。

**入门资料**：
- Woess, *Random Walks on Infinite Graphs and Groups*（图上随机游走的标准教材）
- 离散限制 / 格点调和分析近期文献（Mockenhaupt–Tao 风格的结果，组内分头找）

## 候选 C · 多粒子系统的密度涨落与 SPDE（跨度较大，先列着）

**对象 / 现象**：大量独立随机游动粒子（如对称简单排斥过程 SSEP）组成的系统，其密度涨落场在流体力学极限下收敛到 Edwards–Wilkinson / KPZ 类的线性 SPDE。

**可能的联系**：
- SPDE 的解估计（线性噪声驱动下的时空正则性）本质是色散 / 热半群作用下的 L^p 混合范数估计。
- 但这一头需要补概率与 SPDE 的大量背景，且和"频率解耦"的距离比 A/B 远。

**联系强度**：**猜测为主**（列作远期候选，本轮不展开；组内先读 1–2 篇综述再判断）。

**入门资料**：
